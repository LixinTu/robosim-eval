## 4. 关键代码入口(建议阅读顺序)

1. `scripts/wsl/analyze_attempt.py`:`read_bag`(bag → 各话题序列,ROS 依赖延迟导入)、`parse_goal_transcript`(实际发出的目标与目标 ID)、纯函数 `evaluate`(目标核对、按目标 ID 过滤、`stop_still`、在停稳确认时刻判定到达、数据完整性、A5 枚举与 pass/fail/inconclusive)、`main`(退出码 0/10/11/2/1)。测试:`tests/test_analyze_attempt.py`。
2. `scripts/wsl/start_nav2.sh` / `stop_nav2.sh`:包装进程、`env --default-signal`、SIGINT → SIGTERM → SIGKILL 升级、退出码文件、残留检查。
3. `scripts/wsl/record_d0.sh` / `stop_record.sh`:每个记录器一个会话、`timeout -s INT` 上限、按会话停止、退出码文件。
4. `scripts/wsl/send_goal.sh`:参数校验、地图空闲核对、一次 NavigateToPose 目标、原始反馈与结果转录、退出码反映导航结果。
5. `scripts/windows/start_isaac_ros2.ps1`、`allow_wsl_to_isaac_firewall.ps1`:启动环境变量与防火墙规则范围。
6. `scripts/wsl/install_ros2_jazzy.sh`、`setup_workspace.sh`、`probe_*.sh`、`check_*.sh`:安装与探测。
7. `scripts/windows/run_codex_review.ps1`:只读 Codex 审查启动器(记录真实退出码与是否撞到用量上限)。

## 5. 已知限制(实现者自述,请独立判断是否成立或有遗漏)

- 单次导航尝试,不代表导航性能;碰撞/接触未测量(safety_status=unknown)。

- Nav2 用钉住默认参数;示例场景不发布 2D 雷达扫描,局部代价地图两路观测源无数据。

- attempt-01 是用修复前的记录/停止脚本采集的:没有记录器退出码文件,文本流多跑了约 3 分钟后被手动按会话停止;修复后的脚本只在回归测试中使用过,还没有用于真实导航(用户验收时首次使用)。

- 停止 Nav2 时组件容器 SIGSEGV、launch 退出码 1(三次复测后结束排查)。
- 证据中部分文本较大(goal-202437.txt 2.7 MB);bag 本身不入 Git。
